# Public Repository Checklist

Use this before publishing or pushing changes.

## Files that must stay local

| Local file | Public example |
|---|---|
| `opentofu/terraform.tfvars` | `opentofu/terraform.tfvars.example` |
| `ansible/group_vars/hermes.yml` | `ansible/group_vars/hermes.yml.example` |
| `ansible/group_vars/hermes_vault.yml` | `ansible/group_vars/hermes_vault.yml.example` |
| `ansible/inventory/hosts.ini` | generated by OpenTofu |

## Example network

Public docs and examples should use only this subnet:

```text
10.10.10.0/24
```

Suggested example addresses:

| Host | Example IP |
|---|---|
| Gateway | `10.10.10.1` |
| Ollama model host | `10.10.10.20` |
| Hermes VM | `10.10.10.50` |

## Do not publish

- real LAN IP addresses
- real hostnames
- Windows or Linux usernames
- personal names or aliases
- Proxmox API tokens
- Cloudflare Tunnel connector tokens, dashboard passwords/hashes, Vault passphrases, and session-signing secrets
- private SSH keys
- rendered `.env` files
- rendered `dashboard.env` and `cloudflared.env` files (covered by `*.env`)
- Ansible vault files
- generated inventory files
- OpenTofu state or plan files

## Local setup from examples

```bash
cp opentofu/terraform.tfvars.example opentofu/terraform.tfvars
cp ansible/group_vars/hermes.yml.example ansible/group_vars/hermes.yml
cp ansible/group_vars/hermes_vault.yml.example ansible/group_vars/hermes_vault.yml
```

Edit the local copies only.

## Pre-publish checks

Check tracked files for common private-data patterns:

```bash
git grep -nE '192\.168\.|172\.(1[6-9]|2[0-9]|3[0-1])\.|BEGIN .* KEY'
```

Also search for your own real names, aliases, hostnames, usernames, machine names, and site-specific labels before publishing:

```bash
git grep -niE '<NAME_OR_ALIAS>|<USERNAME>|<HOSTNAME>|<MACHINE_NAME>'
git ls-files | grep -iE '<NAME_OR_ALIAS>|<USERNAME>|<HOSTNAME>|<MACHINE_NAME>'
```

Replace each placeholder with a real value before running the command.

Check whether local-only files are tracked:

```bash
git ls-files opentofu/terraform.tfvars ansible/group_vars/hermes.yml ansible/group_vars/hermes_vault.yml ansible/inventory/hosts.ini
```

Expected result after cleanup: no output except files intentionally being removed from tracking in the current change.

### An ignored file can still be tracked

Adding a path to `.gitignore` does not remove an already tracked file. If the local deployment settings still appear in `git ls-files`, stop tracking them while keeping the actual file on disk:

```bash
git rm --cached -- ansible/group_vars/hermes.yml
```

This stages a deletion from the next commit, not a deletion of the local working file. Check `git status` and confirm the public `hermes.yml.example` contains placeholders/example settings instead of local values.

### Check history before a public push

A clean working tree or a cleanup commit does not erase earlier file contents. Review every commit that would be published, including commits already present in remote-tracking history:

```bash
git log --all --oneline
git log --all --oneline -- ansible/group_vars/hermes.yml ansible/group_vars/hermes_vault.yml opentofu/terraform.tfvars ansible/inventory/hosts.ini
```

For a filename-only check of private-network/key markers in an earlier commit, replace `<COMMIT>` with its hash:

```bash
git grep -l -I -E '192\.168\.|172\.(1[6-9]|2[0-9]|3[0-1])\.|BEGIN .*PRIVATE KEY' <COMMIT>
```

Check other private address ranges and your site-specific names too; these patterns are not a complete secret scan. Keep matching values out of published audit reports. Encrypted Vault files and password hashes remain local-only even if they do not contain plaintext passwords.

If earlier commits contain local-only data, sanitize the publication history before making a public push. Untracking the file in a new commit is only the first step. History cleanup requires a separate, deliberate operation because it changes commit IDs and can affect an existing remote; do not treat a regular cleanup commit as history removal. If credentials were actually published, rotate those credentials as well as removing their historical copies.

Review pending changes before publishing:

```bash
git status --short
git diff -- . ':(exclude)opentofu/terraform.tfvars' ':(exclude)ansible/group_vars/hermes.yml' ':(exclude)ansible/group_vars/hermes_vault.yml' ':(exclude)ansible/inventory/hosts.ini'
```
